# RANI AI — Android wrapper

WebView wrapper around the phone web app in `../rani-web/`.
Package: **`com.badshah222.rani.ai`** • minSdk 24 • targetSdk 34 • Kotlin.

## How it works

RANI is Python (PyQt5) — it cannot become a native Android APK directly.
So, the BADSHAH way: the app is the web app, and this project is a thin
Android shell that loads it in a WebView, with mic/camera permission
handling so voice chat and camera vision work on the phone.

## Build locally (debug APK, no signing needed)

```bash
cd android
./gradlew assembleDebug
# APK: app/build/outputs/apk/debug/app-debug.apk
```

Needs Android SDK + JDK 17. (The `gradle/wrapper/` folder has properties
only; the `gradlew` script itself is generated by Android Studio / Gradle —
run `gradle wrapper` once, or open the folder in Android Studio.)

## App URL

`MainActivity.APP_URL` — default `https://rani-ai-girlfrind.pages.dev`.
Change it at release time to the deployed RANI web app URL. If the hosted
app cannot be reached, a bundled offline page (`assets/offline.html`) is
shown. The full web app is deliberately NOT bundled as local assets, so it
can be updated without shipping a new APK.

## Permissions

Manifest: `INTERNET`, `RECORD_AUDIO`, `CAMERA`, `MODIFY_AUDIO_SETTINGS`,
`ACCESS_NETWORK_STATE`, `POST_NOTIFICATIONS`. Mic/camera are requested at
runtime and also granted inside the WebView (`WebChromeClient`).

## Release signing

No keystore is committed. A signed release APK is built in CI only, from
GitHub Secrets — see `.github/workflows/android-build.yml`.
